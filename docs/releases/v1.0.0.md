# BrowserSwitch v1.0.0 · Windows

Primera versión descargable del selector de navegador por usuario.

## Descargar e instalar

1. Descarga **BrowserSwitch-1.0.0-windows.zip** desde los archivos de esta release.
2. Extrae todo el ZIP, abre **BrowserSwitch.exe** y pulsa **Instalar BrowserSwitch**.
3. Elige BrowserSwitch para **HTTP y HTTPS** en Aplicaciones predeterminadas de Windows.
4. Abre el acceso directo BrowserSwitch del escritorio o del menú Inicio.

No necesitas compilar, Git ni PowerShell para la instalación gráfica. Se requiere Windows 10/11 con .NET Framework 4.8 disponible. La instalación es por usuario, en `%LOCALAPPDATA%\BrowserSwitch`, sin solicitar administrador.

Para actualizar, primero usa **Salir de la bandeja** y cierra los selectores pendientes; después instala desde la carpeta extraída nueva. Las preferencias se conservan.

## Incluye

- Selector HTTP/HTTPS y archivos HTML, con modo fijo o Preguntar siempre.
- Detección de navegadores registrados por usuario y equipo, más entradas manuales.
- Menú residente con una sola instancia y arranque con Windows opcional.
- Iconos integrados para ejecutable, bandeja y accesos directos.
- Registro por usuario y conservación del identificador `SelectorNavegadorPersonal`.
- Instrucciones, scripts opcionales de desinstalación e información de versión dentro del ZIP.
- Archivo **SHA256SUMS.txt** para comprobar la integridad de la descarga.

## Validación y límites

La aplicación tiene 299 comprobaciones locales de lógica, procesos, configuración, registro de detección y recursos gráficos. El paquete se comprueba después de extraerlo, ejecutando su diagnóstico y validando versiones, hashes y contenido.

La validación se realizó en el equipo Windows usado durante el desarrollo. Sigue pendiente comprobar una instalación limpia en otro equipo, el arranque tras reiniciar sesión y el recorrido completo de desinstalación. El ejecutable no está firmado digitalmente. La organización puede restringir su ejecución; esta versión no cambia políticas ni fuerza asociaciones protegidas.

Teams debe usar **Navegador predeterminado** en sus opciones de enlaces. macOS y Linux todavía no están implementados.

El repositorio mantiene su visibilidad privada: la descarga requiere acceso al repositorio. No se incluyen preferencias, rutas personales, historial ni credenciales en el paquete.
